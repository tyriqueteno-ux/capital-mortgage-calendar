# Capital Mortgage Calendar

Private team calendar for Capital Mortgage. Next.js on Vercel, Google sign-in, Google Calendar + Google Tasks.
Business hours (Mon–Sat, 8 AM – 6 PM Central) are enforced server-side.

- Setup: see **SETUP.md**
- Team list and hours: **config/team.js**
- Server routes: `app/api/*` · Hours rules: `lib/hours.js` · Page logic: `public/app.js`
